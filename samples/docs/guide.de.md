# Erste Schritte

Installieren Sie das Tool und führen Sie dann Ihre erste Prüfung aus. Das dauert etwa **5 Minuten.

## Installation

Laden Sie Version 2.5 von [der Release-Seite](https://example.com/de/releases) herunter und entpacken Sie sie.

```bash
tool installieren --channel stable
```

## Erste Prüfung

1. Öffnen Sie ein Terminal in Ihrem Projektordner.
2. Führen Sie `tool prüfen` aus und warten Sie auf die Zusammenfassung.
3. Beheben Sie alles, was mit FAIL markiert ist, bevor Sie veröffentlichen.

# Getting started

Install the tool, then run your first check. It takes about **5 minutes**.

## Install

Download version 2.4 from [the releases page](https://example.com/releases) and unzip it.

```bash
tool install --channel stable
```

## First check

1. Open a terminal in your project folder.
2. Run `tool check` and wait for the summary.
3. Fix anything marked FAIL before you publish.

Never share your API key. If it leaks, revoke it at once from the account page.
